# AI 求职助手平台

多用户 AI 求职工作台：公司官网岗位采集 → 岗位库 → 简历结构化 → 人岗匹配打分 → 简历修改建议。

当前进度：**Phase 5 完成**（骨架 + 多用户 + 多模型 + 手动导入 + 人岗匹配打分 + 简历修改建议 + 五家官网岗位采集 + 投递记录与进展跟踪）。路线图与全部设计决策见 [doc/求职平台调研方案.md](doc/求职平台调研方案.md)。

## 本机开发

```bash
# 后端（Python 3.13+）
cd backend
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt   # Windows Git Bash
cp ../.env.example .env                              # 填 ENCRYPTION_KEY（Fernet 生成命令见文件内注释）
.venv/Scripts/python -m alembic upgrade head
.venv/Scripts/python -m uvicorn app.main:app --reload

# 前端（Node 20+）
cd frontend
npm install
npm run dev    # http://localhost:5173，已代理 /api 到 8000

# 测试
cd backend && .venv/Scripts/python -m pytest -q
```

生产部署用 `docker compose up -d`（web + postgres:16，web 容器自动执行 alembic 迁移）。

## 首次使用

1. 注册第一个账号（**空库首个用户免邀请码并自动成为管理员**——邀请码由管理员创建，避免鸡生蛋）。
2. 管理员在「管理」页生成邀请码 → 朋友凭码注册。
3. 每人在「设置」页配置自己的模型 Provider（DeepSeek/Kimi/GLM/Qwen 等 OpenAI 兼容接口，Key 加密存储、仅显示掩码）。
4. 「岗位」页粘贴 JD → 后台解析入库（管理员可选入共享库，普通用户为私有岗位）。
5. 「简历」页上传 PDF/DOCX/MD → 本地抽取 + LLM 结构化；**脱敏默认开启**（姓名/手机号/邮箱出站前替换为占位符，原文加密存储）。
6. 「岗位」页点「给当前简历批量打分」：先硬规则过滤（经验差 >2 年、学历不够，附排除理由），再按关键词粗排取前 20，最后 LLM 四维打分 + 代码加权；列表显示推荐分并可查看维度分/理由/缺口。单岗也可单独打分，结果按 (简历版本, 岗位) 缓存。
7. 「设置」页调整四维权重（技能匹配/经验相关度/职级与薪资匹配/行业业务匹配），保存后可按新权重重算全部分数。
8. 在匹配详情里点「生成修改建议」：以该岗位的打分结论（维度分、gaps）为输入，产出逐条建议（定位字段 + 原文 → 改写 + 理由 + 优先级）、缺失关键词与防编造提醒；建议与匹配结果绑定缓存，结论不变时不重复调用模型，「按新结论重新生成」可强制重算。
9. 管理员在「管理 → 站点采集」点「同步」：后台抓取五家官网在招岗位——米哈游（约 670 个，列表 + 详情）、腾讯（约 2100 个，列表 + 详情）、B站（约 490 个，免浏览器）、美团（约 3400 个，免浏览器）、字节（列表接口带签名，需在本机起无头 Edge 翻页，每页 10 条）。三家新站点的列表接口已自带 JD 全文，不再抓详情页。所有站点按外部 id 去重（重复同步只更新变化的内容），整轮跑完后把站点上已消失的岗位标记下架。采集结果进共享岗位库，普通用户直接在「岗位」页按推荐分查看并打分；可填「最多抓几条」做小范围试跑。同步间隔 1 秒、失败自动重试，不调用任何模型（零成本）。
10. 岗位列表或匹配详情里点「标记已投递」：把公司、标题、城市、链接、当时的匹配分快照进「投递」页（岗位库后续改名或下架不影响已投记录）。「投递」页按状态推进：已投递 → 笔试 → 面试 → Offer，也可以直接标记「已拒 / 已放弃」；每次变更记入时间线，可附备注。超过 7 天没动静的记录会带「⚠ N 天无动静」角标，可切到「最久未更新」排序，优先跟进。

## 安全基线

- 用户密码 scrypt 散列；JWT 会话（7 天）。
- API Key 与简历原文用 Fernet 加密落库（主密钥来自 `ENCRYPTION_KEY` 环境变量，不入库不入 git，**请备份**）。
- LLM 出站消息脱敏；任何接口不回显完整 Key。
- 数据隔离：简历/私有岗位/调用记录仅本人可见（有权限测试覆盖）。

## 本机冒烟

无真实 Key 也能端到端验证：`cd backend && pwsh -File tools/smoke_run.ps1`（起本地桩模型 + 招聘站点桩 + uvicorn + sqlite，跑完自动清理）。覆盖注册/登录/Provider/打分/建议/五站点采集/投递全流程（投递段断言快照、重复 409、状态推进与时间线、非法状态 400、统计）。

站点采集里的字节适配器需要 Playwright 与本机 Edge（`pip install playwright`，无需 `playwright install` 下载浏览器：适配器用 `channel="msedge"` 复用系统 Edge）；没装时该站点报「需要本地浏览器」而不是 500，其余站点仍可正常同步。
