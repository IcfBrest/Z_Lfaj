3. **限速与重试**：`HttpClient.fetch_json` 未改动；字节走浏览器，不受 `min_interval` 影响，靠 `max_pages` 与 `limit` 约束。

5. **幂等**：`external_id` 为三家共同去重键（字节 `id`、B站 `id`、美团 `jobUnionId`），`PERSIST_FIELDS` 已含 `source_url`，重复采集只更新链接。

## 4. 非阻塞遗留

1. 字节每页固定 10 条、站内上限 1000 页，全量采集需要 ~1000 次翻页（约数小时）；当前用 `SCRAPER_MAX_PAGES=20` 保守限制，后续可加「断开后续跑」的游标。
2. 字节分页依赖 `.atsx-pagination-item[title='N']`，站点改版需同步调整选择器。
3. B站 csrf token 只在 401/-101 时刷新一次，若站点改为滑动过期，需要更细的重试策略。
4. 冒烟未覆盖字节浏览器路径（CI 无 Edge），建议后续加一个「浏览器可用则跑」的可选段。
5. `sources` 的 `mode` 由「适配器是否暴露 `pages` 可调用属性」推断，属于鸭子类型判断；若将来有 HTTP 站点也想自定义分页，语义会冲突。
